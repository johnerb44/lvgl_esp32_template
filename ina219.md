# INA219 Power Bank Monitor for ESP32-S3 LCD Display

## Overview

This document captures a complete design and implementation for monitoring a 25000 mAh 5 V power bank using an INA219 current/voltage monitor IC, displaying remaining power as High/Medium/Low status on an ESP32-S3 LCD display.

## Initial Assessment

**Question:** Will the INA219 schematic work for this application?

**Answer:** Partially.

### Why It Works (Partially)

The INA219 can measure:
1. Output current drawn by the ESP32-S3 system
2. Output voltage on the 5 V rail
3. Instant power and use trends

### Why It Won't Directly Indicate Remaining Capacity

1. A power bank regulates its output near 5 V until close to shutdown, so voltage alone is a poor state-of-charge indicator.
2. INA219 is not a battery fuel-gauge IC; it measures bus voltage and shunt current, not internal cell chemistry or state.
3. "25000 mAh" is rated at cell voltage (~3.7 V), not at 5 V output.

### Solution

**Use coulomb (energy) counting from a known full state.**

- Calibrate usable energy once via a real-world test
- Map accumulated energy consumption to High/Medium/Low thresholds
- Persist totals in NVS (non-volatile storage)
- Provide a user action to reset counters when powerbank is fully recharged

## Concrete ESP-IDF Algorithm

### 1. What You Track

State variables:
- `used_Wh` (float): cumulative output energy consumed
- `used_mAh_5V` (float): cumulative output charge at 5 V rail
- `full_usable_Wh` (float): calibrated usable output energy when bank is truly full
- `soc_pct` (float): remaining percent estimate
- `level` (enum): HIGH, MEDIUM, LOW, UNKNOWN

**Recommended initial `full_usable_Wh`:** 74.0 Wh for a 25000 mAh bank (real output is less than 92.5 Wh theoretical due to conversion losses and cutoff behavior).

### 2. Sampling Interval

Use a fixed **1 second sample period**.

**Why:**
- Good accuracy for integration
- Low CPU load
- Easy debug and stable UI updates

**Task cadence:**
- INA219 sample task: every 1000 ms
- LCD status update: every 1000 ms
- NVS save: every 60 s (or when energy delta ≥ 0.20 Wh)

### 3. INA219 Reading and Filtering

At each sample:
1. Read bus voltage `V_bus_V` (volts)
2. Read load current `I_mA` (mA)
3. Clamp negative current to 0 for discharge-only accounting:
   - `I_mA = max(I_mA, 0)`

**Apply light filtering** to reduce flicker:
- Use exponential moving average (EMA) on current and voltage:
  - `V_f = alpha * V_new + (1 - alpha) * V_f_prev`
  - `I_f = alpha * I_new + (1 - alpha) * I_f_prev`
- Use `alpha = 0.2` (good starting point)

### 4. Integration Math

Let `dt_h = sample_period_seconds / 3600`. For 1 s, `dt_h = 1/3600`.

**Per-sample increments:**
- `d_mAh = I_f * dt_h`
- `d_Wh = (V_f * I_f / 1000.0) * dt_h`

**Accumulate:**
- `used_mAh_5V += d_mAh`
- `used_Wh += d_Wh`

**Remaining and SOC:**
- `remaining_Wh = max(full_usable_Wh - used_Wh, 0)`
- `soc_pct = 100.0 * remaining_Wh / full_usable_Wh`
- Clamp `soc_pct` to [0, 100]

### 5. High/Medium/Low Logic (with Hysteresis)

Use hysteresis to prevent LCD bouncing around thresholds.

**Thresholds:**
- HIGH if `soc_pct >= 60`
- MEDIUM if `25 <= soc_pct < 60`
- LOW if `soc_pct < 25`

**Hysteresis band:** `h = 5` percentage points

**State transitions:**
- HIGH → MEDIUM only when `soc_pct < 60 - 5` (55)
- MEDIUM → HIGH only when `soc_pct > 60 + 5` (65)
- MEDIUM → LOW only when `soc_pct < 25 - 5` (20)
- LOW → MEDIUM only when `soc_pct > 25 + 5` (30)

This gives stable display behavior and prevents flutter.

### 6. NVS Persistence Strategy

**Namespace:** `powermon`

**Keys:**
- `used_wh` (float)
- `used_mah_5v` (float)
- `full_usable_wh` (float)
- `last_soc` (float)
- `epoch_s` (u32 or i64, optional for diagnostics)

**Save policy:**
- Periodic save every 60 s
- Immediate save if `used_Wh` changed by ≥ 0.20 Wh since last save
- Save on graceful shutdown/deep-sleep entry if applicable

**Boot behavior:**
- Read NVS values
- If missing/uninitialized: `used_Wh = 0`, `used_mAh_5V = 0`, `full_usable_Wh = 74.0`
- If corrupted/out-of-range: reset to defaults and log warning

**Wear control:** Do not write every sample. 60 s + delta-trigger is safe and accurate.

### 7. Detect "Powerbank Fully Recharged"

You need a reset condition so `used_Wh` does not grow forever.

**Best method:**
1. Add a user action in UI: "Set Powerbank Full"
2. On action:
   - `used_Wh = 0`
   - `used_mAh_5V = 0`
   - save NVS immediately

**Optional auto-full heuristic (less reliable):**
- If external event indicates full recharge (dock/charger GPIO/event), then reset counters.

### 8. LCD Status Logic

Every 1 second:
1. Show level text: HIGH / MEDIUM / LOW
2. Optional show percent rounded: 83%, 52%, etc.
3. Optional show remaining energy: Rem: 31.4 Wh
4. Sensor fault handling:
   - If INA219 read fails for >5 consecutive samples:
     - Show LEVEL: UNKNOWN
     - Keep last valid `soc_pct` but gray out indicator

### 9. Suggested ESP-IDF Task Layout

1. **powermon_task** (1 s loop)
   - read INA219
   - filter
   - integrate
   - compute SOC
   - update level state machine
   - queue latest struct for UI task

2. **nvs_save_task** (timer/event driven)
   - commit every 60 s or delta threshold

3. **ui_task/LVGL timer**
   - pull latest power status
   - update labels/icons

**Shared struct fields:**
- `voltage_V`
- `current_mA`
- `power_W`
- `used_Wh`
- `remaining_Wh`
- `soc_pct`
- `level`
- `sensor_ok`

### 10. One-Time Calibration Procedure

Do this once to make High/Medium/Low meaningful.

**Procedure:**
1. Fully charge powerbank
2. In firmware, set full (`used_Wh = 0`)
3. Run your real device profile until powerbank cutoff
4. Record final `used_Wh_cutoff`
5. Set `full_usable_Wh = used_Wh_cutoff * 0.95` (small safety margin)
6. Store in NVS
7. Repeat once more and average if you want better accuracy

That gives your system a realistic usable capacity model.

## C Implementation Skeleton (ESP-IDF)

Below is a drop-in single-file C skeleton with ESP-IDF types and APIs, including the data model, NVS load/save helpers, the 1-second integration loop, and the exact hysteresis state machine.

```c
#include <stdio.h>
#include <math.h>
#include <string.h>
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "esp_err.h"
#include "esp_log.h"
#include "esp_timer.h"
#include "nvs.h"
#include "nvs_flash.h"

static const char *TAG = "powermon";

// -------------------- Config --------------------
#define PM_NS                  "powermon"
#define PM_SAMPLE_MS           1000
#define PM_SAVE_PERIOD_MS      60000
#define PM_SAVE_DELTA_WH       0.20f
#define PM_DEFAULT_FULL_WH     74.0f
#define PM_ALPHA               0.20f
#define PM_MAX_SENSOR_FAILS    5

#define PM_T_HIGH              60.0f
#define PM_T_LOW               25.0f
#define PM_HYST                5.0f

// -------------------- Types --------------------
typedef enum {
    PM_LEVEL_UNKNOWN = 0,
    PM_LEVEL_LOW,
    PM_LEVEL_MEDIUM,
    PM_LEVEL_HIGH
} pm_level_t;

typedef struct {
    // Raw/filtered measurement
    float voltage_v;
    float current_ma;
    float power_w;
    float voltage_f_v;
    float current_f_ma;
    bool filter_initialized;

    // Integrated usage
    float used_wh;
    float used_mah_5v;

    // Capacity model
    float full_usable_wh;
    float remaining_wh;
    float soc_pct;

    // UI/status
    pm_level_t level;
    bool sensor_ok;
    uint32_t sensor_fail_count;

    // Persistence book-keeping
    int64_t last_sample_us;
    int64_t last_save_us;
    float used_wh_at_last_save;
} pm_state_t;

// -------------------- Forward declarations --------------------
static esp_err_t ina219_read(float *bus_v, float *current_ma);
static void lcd_update_power_level(pm_level_t level, float soc_pct, float rem_wh, bool sensor_ok);

static esp_err_t pm_nvs_load(pm_state_t *s);
static esp_err_t pm_nvs_save(const pm_state_t *s);

static pm_level_t pm_level_next(pm_level_t current, float soc_pct);
static void pm_update_from_sample(pm_state_t *s, float v_bus, float i_ma, float dt_h);
static bool pm_should_save(const pm_state_t *s, int64_t now_us);
static const char *pm_level_str(pm_level_t l);

// -------------------- NVS --------------------
static esp_err_t pm_nvs_load(pm_state_t *s)
{
    nvs_handle_t h;
    esp_err_t err = nvs_open(PM_NS, NVS_READONLY, &h);
    if (err != ESP_OK) {
        ESP_LOGW(TAG, "NVS open (read) failed: %s, using defaults", esp_err_to_name(err));
        s->used_wh = 0.0f;
        s->used_mah_5v = 0.0f;
        s->full_usable_wh = PM_DEFAULT_FULL_WH;
        return ESP_OK;
    }

    float f = 0.0f;
    err = nvs_get_blob(h, "used_wh", &f, &(size_t){sizeof(float)});
    s->used_wh = (err == ESP_OK) ? f : 0.0f;

    err = nvs_get_blob(h, "used_mah", &f, &(size_t){sizeof(float)});
    s->used_mah_5v = (err == ESP_OK) ? f : 0.0f;

    err = nvs_get_blob(h, "full_wh", &f, &(size_t){sizeof(float)});
    s->full_usable_wh = (err == ESP_OK && f > 1.0f && f < 200.0f) ? f : PM_DEFAULT_FULL_WH;

    nvs_close(h);
    return ESP_OK;
}

static esp_err_t pm_nvs_save(const pm_state_t *s)
{
    nvs_handle_t h;
    esp_err_t err = nvs_open(PM_NS, NVS_READWRITE, &h);
    if (err != ESP_OK) return err;

    err = nvs_set_blob(h, "used_wh", &s->used_wh, sizeof(float));
    if (err == ESP_OK) err = nvs_set_blob(h, "used_mah", &s->used_mah_5v, sizeof(float));
    if (err == ESP_OK) err = nvs_set_blob(h, "full_wh", &s->full_usable_wh, sizeof(float));
    if (err == ESP_OK) err = nvs_commit(h);

    nvs_close(h);
    return err;
}

// -------------------- State machine (exact hysteresis logic) --------------------
static pm_level_t pm_level_next(pm_level_t current, float soc_pct)
{
    if (soc_pct < 0.0f) soc_pct = 0.0f;
    if (soc_pct > 100.0f) soc_pct = 100.0f;

    // Unknown -> choose nearest nominal band
    if (current == PM_LEVEL_UNKNOWN) {
        if (soc_pct >= PM_T_HIGH) return PM_LEVEL_HIGH;
        if (soc_pct < PM_T_LOW) return PM_LEVEL_LOW;
        return PM_LEVEL_MEDIUM;
    }

    // HIGH -> MEDIUM below 55
    if (current == PM_LEVEL_HIGH) {
        if (soc_pct < (PM_T_HIGH - PM_HYST)) return PM_LEVEL_MEDIUM;
        return PM_LEVEL_HIGH;
    }

    // MEDIUM -> HIGH above 65, MEDIUM -> LOW below 20
    if (current == PM_LEVEL_MEDIUM) {
        if (soc_pct > (PM_T_HIGH + PM_HYST)) return PM_LEVEL_HIGH;
        if (soc_pct < (PM_T_LOW - PM_HYST)) return PM_LEVEL_LOW;
        return PM_LEVEL_MEDIUM;
    }

    // LOW -> MEDIUM above 30
    if (current == PM_LEVEL_LOW) {
        if (soc_pct > (PM_T_LOW + PM_HYST)) return PM_LEVEL_MEDIUM;
        return PM_LEVEL_LOW;
    }

    return PM_LEVEL_UNKNOWN;
}

// -------------------- Core update --------------------
static void pm_update_from_sample(pm_state_t *s, float v_bus, float i_ma, float dt_h)
{
    // Clamp discharge-only accounting
    if (i_ma < 0.0f) i_ma = 0.0f;
    if (v_bus < 0.0f) v_bus = 0.0f;

    s->voltage_v = v_bus;
    s->current_ma = i_ma;

    if (!s->filter_initialized) {
        s->voltage_f_v = v_bus;
        s->current_f_ma = i_ma;
        s->filter_initialized = true;
    } else {
        s->voltage_f_v = PM_ALPHA * v_bus + (1.0f - PM_ALPHA) * s->voltage_f_v;
        s->current_f_ma = PM_ALPHA * i_ma  + (1.0f - PM_ALPHA) * s->current_f_ma;
    }

    s->power_w = (s->voltage_f_v * s->current_f_ma) / 1000.0f;

    float d_mah = s->current_f_ma * dt_h;
    float d_wh  = s->power_w * dt_h;

    s->used_mah_5v += d_mah;
    s->used_wh += d_wh;

    if (s->used_wh < 0.0f) s->used_wh = 0.0f;
    if (s->full_usable_wh < 1.0f) s->full_usable_wh = PM_DEFAULT_FULL_WH;

    s->remaining_wh = s->full_usable_wh - s->used_wh;
    if (s->remaining_wh < 0.0f) s->remaining_wh = 0.0f;

    s->soc_pct = 100.0f * (s->remaining_wh / s->full_usable_wh);
    if (s->soc_pct < 0.0f) s->soc_pct = 0.0f;
    if (s->soc_pct > 100.0f) s->soc_pct = 100.0f;

    s->level = pm_level_next(s->level, s->soc_pct);
}

static bool pm_should_save(const pm_state_t *s, int64_t now_us)
{
    bool periodic = (now_us - s->last_save_us) >= ((int64_t)PM_SAVE_PERIOD_MS * 1000);
    bool delta_wh = fabsf(s->used_wh - s->used_wh_at_last_save) >= PM_SAVE_DELTA_WH;
    return periodic || delta_wh;
}

static const char *pm_level_str(pm_level_t l)
{
    switch (l) {
        case PM_LEVEL_LOW:    return "LOW";
        case PM_LEVEL_MEDIUM: return "MEDIUM";
        case PM_LEVEL_HIGH:   return "HIGH";
        default:              return "UNKNOWN";
    }
}

// Optional UI action: call this when user confirms powerbank is fully charged
void pm_mark_full(pm_state_t *s)
{
    s->used_wh = 0.0f;
    s->used_mah_5v = 0.0f;
    s->remaining_wh = s->full_usable_wh;
    s->soc_pct = 100.0f;
    s->level = PM_LEVEL_HIGH;
    esp_err_t err = pm_nvs_save(s);
    if (err == ESP_OK) {
        s->used_wh_at_last_save = s->used_wh;
        s->last_save_us = esp_timer_get_time();
    }
}

// -------------------- Task --------------------
static void powermon_task(void *arg)
{
    pm_state_t s = {0};
    s.full_usable_wh = PM_DEFAULT_FULL_WH;
    s.level = PM_LEVEL_UNKNOWN;

    ESP_ERROR_CHECK(pm_nvs_load(&s));

    int64_t now_us = esp_timer_get_time();
    s.last_sample_us = now_us;
    s.last_save_us = now_us;
    s.used_wh_at_last_save = s.used_wh;

    while (1) {
        now_us = esp_timer_get_time();
        float dt_h = (float)(now_us - s.last_sample_us) / 1000000.0f / 3600.0f;
        s.last_sample_us = now_us;

        float v_bus = 0.0f, i_ma = 0.0f;
        esp_err_t err = ina219_read(&v_bus, &i_ma);

        if (err == ESP_OK) {
            s.sensor_ok = true;
            s.sensor_fail_count = 0;

            pm_update_from_sample(&s, v_bus, i_ma, dt_h);
        } else {
            if (s.sensor_fail_count < UINT32_MAX) s.sensor_fail_count++;
            s.sensor_ok = (s.sensor_fail_count <= PM_MAX_SENSOR_FAILS);
            if (!s.sensor_ok) s.level = PM_LEVEL_UNKNOWN;
        }

        if (pm_should_save(&s, now_us)) {
            err = pm_nvs_save(&s);
            if (err == ESP_OK) {
                s.last_save_us = now_us;
                s.used_wh_at_last_save = s.used_wh;
            } else {
                ESP_LOGW(TAG, "NVS save failed: %s", esp_err_to_name(err));
            }
        }

        lcd_update_power_level(s.level, s.soc_pct, s.remaining_wh, s.sensor_ok);

        ESP_LOGI(TAG, "V=%.3fV I=%.1fmA P=%.3fW used=%.3fWh rem=%.3fWh soc=%.1f%% level=%s ok=%d",
                 s.voltage_f_v, s.current_f_ma, s.power_w, s.used_wh, s.remaining_wh,
                 s.soc_pct, pm_level_str(s.level), s.sensor_ok);

        vTaskDelay(pdMS_TO_TICKS(PM_SAMPLE_MS));
    }
}

// -------------------- App entry --------------------
void app_main(void)
{
    ESP_ERROR_CHECK(nvs_flash_init());
    // Initialize I2C and INA219 driver before starting task.
    // ina219_init(...);

    xTaskCreate(powermon_task, "powermon_task", 4096, NULL, 5, NULL);
}
```

## Charging Detection

### Can INA219 Detect When the Powerbank is Charging?

**Short answer:** Yes, in principle—but not reliably with typical output-side wiring.

### Why It's Not Reliable in Your Setup

For your current use (monitoring 5 V output to ESP32), INA219 usually sees discharge current only. With that placement:

1. If powerbank is being charged through its own input port while your ESP32 is still powered from output, INA219 may still show positive load current and cannot reliably tell "charging state."
2. If your load is off during charging, INA219 on output side will likely read near 0 mA, not true charging current.

### How to Detect Charging Reliably

1. **Measure on the charging path with a second sensor:** Add a second INA219 or current sense on the input/charging path, where current reverses during charging.
2. **Add a charger-status signal:** Use a GPIO input from the powerbank's charger IC or USB input detect circuit (if available).
3. **Use bidirectional placement:** Wire INA219 to measure current flow in both directions and treat negative current as charging.

**Conclusion:** INA219 can detect charging direction in principle, but with your likely output-side wiring it is not a dependable "powerbank is charging" indicator. Use a dedicated GPIO or secondary sensor if charging-state detection is important to your application.
