This program is the GUI application for a secure lockbox system running on an ESP32-S3 with an 800×480 Waveshare ESP32-S3-Touch-LCD-4.3 module ( https://www.waveshare.com/wiki/ESP32-S3-Touch-LCD-4.3 ), developed in C using ESP-IDF 5.1.6 and LVGL 9.3.0. The Waveshare ESP32-S3-Touch-LCD-4.3 module is a 4.3 inch touch LCD that includes an ESP32-S3 mpu, an SD card, I2C and SPI interfaces as well as several other interfaces. User records are stored on an SD card in a JSON file that conforms to the provided JSON Schema and are manipulated using cJSON. This GUI application is built around the LVGL library, v9.3. The IDE I use for coding is vscode.
